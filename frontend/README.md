# Bible QA - Frontend

This is the frontend application for the Bible QA project.

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Run the development server:
   ```bash
   pnpm dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/`: Next.js App Router pages
- `components/`: React components
- `lib/`: Utility functions and API helpers
- `public/`: Static assets

## Features

- **Profile Selection**: Choose between different user profiles (Mom, Dad, Me, Brother).
- **Chat Interface**: Ask questions about the Bible and get AI-generated answers with scripture references.
- **Conversation History**: View and manage past conversations per profile.
- **Dark Mode**: Fully supported dark theme.
- **Responsive Design**: Optimized for mobile, tablet, and desktop.
